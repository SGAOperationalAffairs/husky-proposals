# Prototypes

Open these HTML files directly in a browser. They use sample data held in memory, so nothing is saved.

- `concept-2.html` is the main one: the student view and the SGA view together, sharing data. Use the switch at the top. Actions on one side show up on the other.
- `sga-view-final.html` is the settled SGA layout on its own.
- `archive/` holds earlier concepts and design sandboxes (card, Learn more page, UI playground, pattern comparison, vote button ideas). They are useful for the reasoning behind design choices, but they are out of date. See `../docs/prototype-vs-prd-gaps.md`.
